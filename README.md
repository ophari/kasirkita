# KasirKita

Aplikasi kasir rumah makan berbasis web — HTML + CSS + JavaScript saja, tanpa build step dan tanpa CDN (jalan offline, buka `index.html` langsung di browser).

## Fitur

- Daftar menu (9 menu: makanan, minuman, camilan) + filter kategori
- Keranjang: tambah, ubah jumlah, hapus item
- Diskon (%), pajak 10%, hitung kembalian + tombol uang cepat (Uang Pas / 50.000 / 100.000 / 200.000)
- Validasi input (diskon 0–100, uang tunai harus angka dan cukup)
- Struk pembayaran + tombol transaksi baru

## Cara pakai

Buka `index.html` di browser. Tidak perlu server, tidak perlu install apa-apa.
